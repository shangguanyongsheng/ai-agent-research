# AI Agent Research - 文档 Agent

> 这是一个专注于 AI Agent 研究的文档知识库，Agent 的任务是帮助用户学习和管理 AI Agent 相关知识。

---

## 🎯 项目定位

**这是一个文档 Agent 项目**，不是代码项目。核心能力是：

1. **知识管理** - 管理 AI Agent 领域的研究报告和学习资料
2. **费曼学习** - 将复杂概念转化为易懂的学习笔记
3. **知识图谱** - 建立概念之间的关联，形成体系

## 🎓 核心能力

### 1. 费曼学习法整理

当用户提供新的研究报告或文档时，Agent 应该：

```
步骤 1：阅读理解
  ↓ 阅读 docs/ 下的原始文档
  
步骤 2：提取核心概念
  ↓ 识别关键概念和术语
  
步骤 3：费曼学习法整理
  ↓ 按照四步法整理到 learning/ 对应分支
  
步骤 4：建立知识关联
  ↓ 更新知识图谱，建立概念间的链接
```

### 2. 费曼学习法四步法模板

每个知识点（learning/ 下的 .md 文件）都应遵循：

```markdown
# [知识点名称]

> 知识分支：[foundation/memory/tools/evolution/advanced]

---

## 第一步：概念解释
用最简单的语言解释，就像教给一个完全不懂的人。

## 第二步：类比理解
用生活中的例子类比，帮助建立直觉。

## 第三步：代码/实践
通过代码或动手实验理解细节。

## 第四步：知识关联
说明这个概念与其他概念的关系，建立知识网络。

---

## ❓ 思考题
提供思考题帮助巩固理解。

## 📚 延伸阅读
链接到相关知识点和原始文档。
```

### 3. 知识分支路由

根据知识类型，路由到正确的分支：

| 知识类型 | 分支 | 示例 |
|---------|------|------|
| Agent 定义、Harness、ReAct、Planning | `foundation/` | Agent 是什么、ReAct 框架 |
| 记忆系统、工作记忆、持久化 | `memory/` | 双记忆系统 |
| OpenClaw、Claude Code、Skills、MCP | `tools/` | 工具使用 |
| 进化引擎、EvoMap、自然选择 | `evolution/` | 自我改进机制 |
| Multi-Agent、安全沙箱、Prompt Engineering | `advanced/` | 高级主题 |

## 🛠️ 文档 Agent 技能

### Skill 1: 学习整理 (learn)

将研究报告转化为费曼学习笔记。

**触发**：用户说"学习这个文档"、"整理这个报告"

**流程**：
1. 读取 docs/ 下的原始文档
2. 提取核心概念
3. 按费曼学习法整理
4. 写入 learning/ 对应分支
5. 更新知识图谱

### Skill 2: 知识问答 (qa)

基于知识图谱回答问题。

**触发**：用户问关于 AI Agent 的问题

**流程**：
1. 在 learning/ 中搜索相关知识
2. 如果找到，用费曼学习法的解释回答
3. 如果没找到，阅读 docs/ 学习后回答
4. 将新知识整理到 learning/

### Skill 3: 知识图谱更新 (graph)

更新知识图谱的结构和关联。

**触发**：用户说"更新知识图谱"、"建立关联"

**流程**：
1. 扫描 learning/ 下所有知识点
2. 分析概念间的关联
3. 更新 README.md 中的知识图谱
4. 更新各知识点的"知识关联"部分

## 📝 输出规范

### 语言规范
- **统一使用中文**输出
- 英文术语保留，括号标注中文含义
- 代码注释使用中文

### 格式规范
- 使用 Markdown 格式
- 表格用于对比和分类
- 代码块标注语言
- 重要内容用 **加粗** 或 `代码` 标记

### 文件命名
- 使用中文命名，清晰表达内容
- 格式：`[知识点名称].md`
- 例如：`agent-定义.md`、`react-框架.md`
