# 知识问答技能

> 基于知识图谱回答 AI Agent 相关问题

---

## 触发条件

用户问关于 AI Agent 的问题时触发。

---

## 执行流程

```
┌─────────────────────────────────────────────────────┐
│              知识问答流程                            │
├─────────────────────────────────────────────────────┤
│                                                     │
│  Step 1: 理解问题                                   │
│  ├── 提取关键概念                                   │
│  └── 确定问题类型（是什么/怎么做/为什么）           │
│                                                     │
│  Step 2: 搜索知识                                   │
│  ├── 在 learning/ 中搜索相关知识点                  │
│  └── 如果找到多个，选择最相关的                     │
│                                                     │
│  Step 3: 组织回答                                   │
│  ├── 使用费曼学习法的解释                           │
│  ├── 提供类比和例子                                 │
│  └── 推荐相关知识点                                 │
│                                                     │
│  Step 4: 学习补充（如果没找到）                     │
│  ├── 阅读 docs/ 相关文档                            │
│  ├── 创建新的学习笔记                               │
│  └── 回答用户                                       │
│                                                     │
└─────────────────────────────────────────────────────┘
```

---

## 回答模板

### 找到知识点时

```markdown
## [概念名称]

**给小孩解释**：
> [简单解释]

**类比理解**：
[类比表格或说明]

**详细说明**：
[详细解释]

**知识关联**：
- 相关概念：[概念A]、[概念B]
- 完整学习：learning/[分支]/[知识点].md
```

### 没找到时

```markdown
我还没学过这个概念，让我先学习一下...

[阅读 docs/ 相关文档]

[创建学习笔记]

现在我来回答你的问题：

**[概念名称] 是...**
[回答内容]

我已经把这个知识点整理到 learning/ 了！
```

---

## 搜索策略

1. **精确匹配**：直接搜索概念名称
2. **模糊匹配**：搜索相关关键词
3. **关联搜索**：从已知知识点跳转

---

## 常见问题类型

| 问题类型 | 关键词 | 回答重点 |
|---------|--------|---------|
| 是什么 | 什么是、定义 | 概念解释 + 类比 |
| 怎么做 | 如何、怎么 | 步骤 + 代码示例 |
| 为什么 | 为什么、原因 | 原因 + 背景 |
| 对比 | 区别、比较 | 对比表格 |
| 关系 | 关系、关联 | 知识图谱 + 关联说明 |
