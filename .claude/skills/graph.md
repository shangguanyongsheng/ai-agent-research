---

## 触发条件

用户说以下内容时触发：
- "更新知识图谱"
- "建立知识关联"
- "整理知识结构"

---

## 执行流程

```
┌─────────────────────────────────────────────────────┐
│              知识图谱更新流程                        │
├─────────────────────────────────────────────────────┤
│                                                     │
│  Step 1: 扫描知识点                                 │
│  ├── 遍历 learning/ 所有分支                        │
│  ├── 收集所有知识点文件                             │
│  └── 提取知识点名称和分类                           │
│                                                     │
│  Step 2: 分析关联                                   │
│  ├── 检查每个知识点的"知识关联"部分                 │
│  ├── 识别概念间的引用关系                           │
│  └── 构建关联图                                     │
│                                                     │
│  Step 3: 更新 README                                │
│  ├── 更新知识图谱图示                               │
│  ├── 更新分支知识点列表                             │
│  └── 更新学习路径                                   │
│                                                     │
│  Step 4: 反向链接                                   │
│  └── 在被引用的知识点中添加反向链接                 │
│                                                     │
└─────────────────────────────────────────────────────┘
```

## 知识图谱格式

### 总览图

```markdown
                            AI Agent 知识体系
                                  │
    ┌──────────┬──────────┬───────┴───────┬──────────┐
    ▼          ▼          ▼               ▼          ▼
foundation  memory     tools         evolution  advanced
(基础)      (记忆)     (工具)         (进化)     (进阶)
    │          │          │               │          │
    ▼          ▼          ▼               ▼          ▼
知识点列表   知识点列表  知识点列表      知识点列表  知识点列表
```

### 分支表格

```markdown
### 1️⃣ foundation/ - 基础概念

| 知识点 | 文件 | 关联概念 |
|--------|------|----------|
| Agent 定义 | agent-定义.md | Agent Harness |
| Agent Harness | agent-harness.md | Agent, Skills |
| ReAct 框架 | react-框架.md | Planning, Tools |
```

---

## 关联类型

| 关联类型 | 说明 | 标记 |
|---------|------|------|
| 前置依赖 | 学习 A 前需要先学 B | B → A |
| 组成关系 | A 是 B 的组成部分 | A ⊂ B |
| 对比关系 | A 和 B 可以对比 | A ↔ B |
| 应用关系 | A 是 B 的应用场景 | A uses B |

2. **各分支知识点列表**
3. **学习路径推荐**
