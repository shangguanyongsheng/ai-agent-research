# 文档学习技能

> 将研究报告转化为费曼学习笔记

---

## 触发条件

用户说以下内容时触发：
- "学习这个文档"
- "整理这个报告"
- "把这个加到知识图谱"
- "费曼学习法整理"

---

## 执行流程

```
┌─────────────────────────────────────────────────────┐
│              文档学习流程                            │
├─────────────────────────────────────────────────────┤
│                                                     │
│  Step 1: 定位文档                                   │
│  ├── 用户指定：读取指定路径                         │
│  └── 未指定：扫描 docs/ 最新文档                    │
│                                                     │
│  Step 2: 提取概念                                   │
│  ├── 识别关键术语                                   │
│  ├── 识别核心概念                                   │
│  └── 识别概念关系                                   │
│                                                     │
│  Step 3: 分类路由                                   │
│  ├── foundation → 基础概念                          │
│  ├── memory → 记忆系统                              │
│  ├── tools → 工具平台                               │
│  ├── evolution → 进化系统                           │
│  └── advanced → 进阶主题                            │
│                                                     │
│  Step 4: 费曼整理                                   │
│  ├── 概念解释（简单语言）                           │
│  ├── 类比理解（生活例子）                           │
│  ├── 代码/实践（动手实验）                          │
│  └── 知识关联（概念关系）                           │
│                                                     │
│  Step 5: 写入文件                                   │
│  ├── 创建 learning/{分支}/{知识点}.md               │
│  └── 更新 learning/README.md                       │
│                                                     │
└─────────────────────────────────────────────────────┘
```

## 分类规则

| 关键词 | 分支 | 示例 |
|--------|------|------|
| Agent, Harness, ReAct, Thought, Action | foundation | Agent 定义, ReAct 框架 |
| Memory, 记忆, 存储, 持久化 | memory | 双记忆系统 |
| OpenClaw, Claude Code, Skill, MCP, Tool | tools | OpenClaw 使用 |
| Evolution, 进化, EvoMap, GDI, Gene, Capsule | evolution | EvoMap 网络 |
| Multi-Agent, 协作, Safety, 沙箱, Prompt | advanced | 安全沙箱 |

---

## 注意事项

1. **不要重复创建**：检查 learning/ 下是否已有相同知识点
2. **保持简洁**：每个知识点聚焦一个概念
3. **建立关联**：必须包含"知识关联"部分
4. **更新图谱**：创建新知识点后更新 README.md
