# 研究到知识图谱

> 从一个名词或 URL 开始，完成调研→文档→知识图谱的完整流程

---

## 🎯 功能

输入一个主题（名词或 URL），自动完成：

1. **调研** - 搜索/访问/学习
2. **文档** - 生成研究报告到 `docs/`
3. **图谱** - 整理知识到 `learning/`

---

## 📋 触发条件

用户说以下内容时触发：

- "调研 XXX"
- "学习 XXX"
- "研究一下 XXX"
- "帮我了解 XXX"
- "分析这个链接 XXX"

---

## 🔄 执行流程

```
┌─────────────────────────────────────────────────────────────┐
│                    完整执行流程                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Step 1: 分析输入                                           │
│  ├── URL？→ 使用 web_fetch 获取内容                         │
│  └── 名词？→ 使用 web_search 搜索多个来源                   │
│                                                             │
│  Step 2: 调研学习                                           │
│  ├── 阅读内容                                               │
│  ├── 提取核心概念                                           │
│  └── 理解技术原理                                           │
│                                                             │
│  Step 3: 生成报告                                           │
│  ├── 创建 docs/[主题]研究报告.md                            │
│  ├── 包含：概念、原理、架构、应用                            │
│  └── 提交到 GitHub                                          │
│                                                             │
│  Step 4: 知识图谱                                           │
│  ├── 分类到对应分支                                         │
│  ├── 按费曼学习法整理                                        │
│  ├── 创建 learning/[分支]/[知识点].md                       │
│  └── 更新 learning/README.md                                │
│                                                             │
│  Step 5: 最终提交                                           │
│  └── git add . && git commit && git push                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
