## 费曼学习法

每个知识点都采用四步结构：

```
1. 概念解释 → 用最简单的话说明是什么
2. 类比理解 → 用生活中的例子类比
3. 实践示例 → 代码和命令示例
4. 知识关联 → 与其他概念的关系
```
