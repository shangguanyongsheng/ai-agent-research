# 双记忆系统

> 知识分支：memory（记忆系统）

---

## 🎯 学习目标

理解 Agent 的双记忆系统：长期记忆 vs 工作记忆

---

## 第一步：概念解释

### 双记忆系统是什么？

**给小孩解释**：
> Agent 有两个"脑子"：
> - **长期记忆**：像日记本，永远保存重要的东西
> - **工作记忆**：像便签纸，用完就扔

**一句话定义**：
> 双记忆系统 = 持久化存储（长期）+ 临时上下文（工作）

### 结构图

```
┌─────────────────────────────────────────────────────┐
│                   双记忆系统                         │
├─────────────────────────────────────────────────────┤
│                                                     │
│   长期记忆（持久化）          工作记忆（临时）        │
│   ├─ 全局规则 BI_RULES.md    ├─ 当前会话上下文      │
│   ├─ 用户记忆 users/         ├─ 错误日志            │
│   └─ 历史对话                └─ 纠正记录            │
│                                                     │
│   生命周期：永久              生命周期：会话内        │
│                                                     │
└─────────────────────────────────────────────────────┘
```

| 记忆类型 | 存储位置 | 生命周期 | 用途 |
|---------|---------|---------|------|
| 全局记忆 | BI_RULES.md | 永久 | 存放通用规则 |
| 用户记忆 | users/{user_id}/ | 永久 | 存放用户偏好 |
| 工作记忆 | 内存 | 会话内 | 临时存放上下文 |

---

## 第二步：类比理解

### 类比：人类记忆

| Agent 记忆 | 人类记忆 | 例子 |
|-----------|---------|------|
| 全局记忆 | 长期知识 | 会骑自行车 |
| 用户记忆 | 对某人的印象 | 小明喜欢喝咖啡 |
| 工作记忆 | 短期记忆 | 刚才说的电话号码 |

### 类比：电脑存储

| Agent 记忆 | 电脑对应 | 特点 |
|-----------|---------|------|
| 长期记忆 | 硬盘 | 永久保存 |
| 工作记忆 | 内存 | 断电丢失 |

## 第三步：实际应用

### 记忆文件结构

```
workspace/
├── AGENTS.md           # 全局行为准则
├── MEMORY.md           # 长期记忆
├── USER.md             # 用户信息
├── memory/             # 日记目录
│   └── 2026-03-23.md   # 每日记录
└── skills/             # 技能记忆
```

### 记忆的读写

```python
# 读取长期记忆
def read_memory():
    with open("MEMORY.md", "r") as f:
        return f.read()

# 写入长期记忆
def write_memory(content):
    with open("MEMORY.md", "a") as f:
        f.write(content)

# 工作记忆（内存中）
working_memory = []

def add_to_working(item):
    working_memory.append(item)
    # 会话结束后自动清空
```
