# 🟡 04 — Agent 怎么记住？（记忆系统）

> 💡 一句话：**长期记忆（永久保存）+ 工作记忆（用完就扔）= 双脑系统。**

---

## 30 秒入门

你有没有这种经历：
- 小时候学骑自行车，现在还会 → **长期记忆**
- 别人刚报的手机号，转头就忘 → **工作记忆**

Agent 也是这样。

---

## 双记忆系统

| 记忆类型 | 类比人类 | 类比电脑 | 存什么 | 生命周期 |
|---------|---------|---------|--------|---------|
| **长期记忆** | 技能和知识 | 💾 硬盘 | 用户偏好、项目规则、教训 | 永久 |
| **工作记忆** | 短期记忆 | 🧠 内存 | 当前任务的上下文 | 会话结束就清空 |

## 实际文件结构

```
workspace/
├── AGENTS.md          # Agent 的行为准则（"价值观"）
├── SOUL.md            # Agent 的性格（说话风格）
├── USER.md            # 用户信息（名字、时区、偏好）
├── MEMORY.md          # 长期记忆（重要事件、教训）
├── memory/            # 日记目录
│   └── 2026-04-16.md  # 今天的记录
└── skills/            # 技能目录
```

## 读写示例

**长期记忆（写文件）**：
```
用户："记住，我的时区是 Asia/Shanghai"
Agent：写入 USER.md → "Timezone: Asia/Shanghai"
# 下次启动时读取，就知道你的时区了 ✅
```

**工作记忆（内存中）**：
```
用户："帮我分析这个 10MB 的 CSV"
Agent：读取文件内容到内存 → 分析 → 输出结果
# 会话结束后，这 10MB 数据从内存清空 ✅
```

## 为什么不能只有一种记忆？

**只有工作记忆** → 每次启动都失忆，永远在重新认识你
**只有长期记忆** → 越存越大，启动越来越慢，噪音越来越多

> 双记忆 = 该记的记住，该忘的忘掉。

## 总结

> 长期记忆是 Agent 的"人生经验"，工作记忆是"当前注意力"。
