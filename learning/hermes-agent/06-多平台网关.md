# 06-多平台网关

> 理解 Hermes Gateway：如何在 Telegram、Discord、Slack、WhatsApp、Signal 等 15+ 平台上使用 Hermes。

---

## 第一步：概念解释

### 什么是 Gateway？

**Gateway** 是一个后台进程，连接到所有你配置的消息平台，处理消息、运行会话、执行 Cron 任务。

核心职责：
- 接收各平台的消息
- 路由到 Agent 处理
- 返回响应到平台
- 运行 Cron 调度器（每 60 秒 tick）
- 管理用户授权（允许列表 + DM 配对）

## 第二步：类比理解

### Gateway = 公司的前台接待系统

CLI → 直接走进办公室
Gateway → 通过电话/邮件/网站联系

**类比：**

```
传统聊天机器人：
- 只有一个入口（比如只在 Telegram）
- 每个平台需要单独部署

Hermes Gateway：
- 一个前台接待系统
- 接听所有电话（Telegram/Discord/Slack...）
- 转给同一个 Agent（核心员工）
- Agent 回复后，前台送回对应渠道
```

### 会话管理 = 每个渠道的对话历史

```
Telegram 私聊：
- 有自己的对话历史
- 重置策略：每天 4AM 或空闲 1440 分钟

Discord 频道：
- 有自己的对话历史
- 可以设置不同的重置策略

跨平台连续性：
- 在 Telegram 开始对话
- 在 CLI 继续（用 /resume）
```

## 第三步：代码/实践

### 快速配置

```bash
hermes gateway setup  # 交互式配置所有平台
```

这个命令：
- 箭头键选择平台
- 显示已配置的平台
- 完成后可选启动 Gateway

---

### Gateway 命令

```bash
# 运行
hermes gateway              # 前台运行
hermes gateway install      # 安装为用户服务
sudo hermes gateway install --system  # Linux: 启动时系统服务

# 管理
hermes gateway start        # 启动服务
hermes gateway stop         # 停止服务
hermes gateway status       # 查看状态
```

---

### Slash 命令（在消息平台中）

| 命令 | 说明 |
|------|------|
| `/new` 或 `/reset` | 新对话 |
| `/model [provider:model]` | 切换模型 |
| `/personality [name]` | 设置个性 |
| `/retry` | 重试上一条 |
| `/undo` | 撤销上一轮 |
| `/status` | 会话信息 |
| `/stop` | 停止正在运行的 Agent |
| `/approve` | 批准待处理的危险命令 |
| `/sethome` | 设为 Home Channel |
| `/compress` | 压缩上下文 |
| `/background <prompt>` | 后台运行任务 |
| `/voice on/off/tts` | 控制语音回复 |
| `/skills` | 浏览技能 |

---

### 会话重置策略

```json
// ~/.hermes/gateway.json
{
  "reset_by_platform": {
    "telegram": { "mode": "idle", "idle_minutes": 240 },
    "discord": { "mode": "idle", "idle_minutes": 60 }
  }
}
```

| 策略 | 默认 | 说明 |
|------|------|------|
| Daily | 4:00 AM | 每天固定时间重置 |
| Idle | 1440 min | 空闲 N 分钟后重置 |
| Both | — | 两者任一触发 |

### 用户授权

#### 允许列表（推荐）

```bash
# 按平台设置
TELEGRAM_ALLOWED_USERS=123456789,987654321
DISCORD_ALLOWED_USERS=123456789012345678
SIGNAL_ALLOWED_USERS=+155****4567
EMAIL_ALLOWED_USERS=trusted@example.com

# 或全局设置
GATEWAY_ALLOWED_USERS=123456789,987654321
```

#### DM 配对（替代方案）

```bash
# 未知用户会收到配对码
# "配对码：XKGH5N7P"

# 你批准
hermes pairing approve telegram XKGH5N7P

# 其他命令
hermes pairing list                # 查看
hermes pairing revoke telegram 123456789  # 移除
```

---

### 中断 Agent

```
# Agent 正在执行时，发送新消息即可中断
# 特点：
# - 正在执行的终端命令立即被 kill（SIGTERM → SIGKILL）
# - 工具调用被取消（只执行当前一个）
# - 多条消息合并成一条 prompt
# - /stop 命令：中断但不排队后续消息
```

### 后台会话

```bash
/background Check all servers and report any that are down
```

**特点：**
- 独立会话，不影响主对话
- 继承当前模型/工具配置
- 完成后自动返回结果到同一对话

### 服务管理

#### Linux (systemd)

```bash
hermes gateway install        # 用户服务
hermes gateway start
journalctl --user -u hermes-gateway -f  # 日志

# 启用 lingering（注销后继续运行）
sudo loginctl enable-linger $USER

# 系统服务（启动时运行）
sudo hermes gateway install --system
sudo hermes gateway start --system
journalctl -u hermes-gateway -f
```

#### macOS (launchd)

```bash
hermes gateway install
hermes gateway start
tail -f ~/.hermes/logs/gateway.log  # 日志
```

## 🎯 关键理解

1. **Gateway 是统一入口**：一个进程连接所有平台
2. **会话隔离**：每个平台/对话有独立的会话历史
3. **安全授权**：允许列表或 DM 配对
4. **可中断**：发送新消息即可中断正在执行的任务
5. **后台会话**：`/background` 让 Agent 独立处理任务
