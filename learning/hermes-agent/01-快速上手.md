# 01-快速上手

> 从安装到第一次对话，60 秒内完成 Hermes Agent 的基本配置。

---

## 第一步：概念解释

**Hermes Agent 是什么？**

Hermes Agent 是一个能自我改进的 AI Agent。它不是绑定在 IDE 的代码助手，也不是单一 API 的聊天机器人。它是一个自主运行的 Agent，越运行越聪明。

核心特点：
- **学习闭环**：自动创建技能、改进技能、保存记忆
- **多平台**：可在 Telegram、Discord、Slack、CLI 等平台使用
- **多模型**：支持 18+ Provider，随时切换
- **终端后端**：可在本地、Docker、SSH、云上运行

---

## 第二步：类比理解

**把它想象成一个实习生**

传统聊天机器人 → 像 ChatGPT，每次对话都是新的，不记得你
代码助手 → 像 Copilot，只懂代码，绑在 IDE 里
Hermes Agent → 像一个实习生，能：
  - 执行终端命令
  - 记住你的项目偏好
  - 学习新技能并保存
  - 在 Telegram 和电脑上都能工作

**关键类比：学习闭环 = 实习生的笔记本**

每次完成复杂任务后，实习生会在笔记本上记录：
- "这个项目用 Go 1.22 + sqlc"
- "这个服务器的 SSH 端口是 2222"
- "这个流程我学会了，下次直接用"

Hermes 的 Skills 和 Memory 就是这个笔记本。

## 第三步：代码/实践

### 安装（Linux/macOS/WSL2）

```bash
# 一行安装
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash

# 重载 shell
source ~/.bashrc  # 或 source ~/.zshrc
```

### Android (Termux)

```bash
# 需要手动路径，详见 Termux guide
pip install "hermes-agent[termux]"
```

### Windows

```bash
# 不支持原生 Windows，需要 WSL2
# 安装 WSL2 后，在 WSL 终端里运行上面的安装命令
```

---

### 选择 Provider

```bash
hermes model  # 交互式选择模型提供商
```

支持的 Provider：

| Provider | 说明 |
|----------|------|
| Nous Portal | 订阅制，零配置（OAuth 登录） |
| OpenRouter | 200+ 模型路由（需要 API Key） |
| OpenAI | ChatGPT（Codex 模型） |
| Anthropic | Claude（Pro/Max 或 API Key） |
| Z.AI/GLM | 智谱模型（需要 API Key） |
| DeepSeek | DeepSeek API |
| 自定义端点 | VLLM/Ollama/OpenAI兼容 API |

### 第一次对话

```bash
hermes  # 启动 CLI
```

你会看到欢迎界面，显示：
- 当前模型
- 可用工具
- 已安装技能

示例对话：

```
❯ What can you help me with?
❯ What's my disk usage? Show the top 5 largest directories.
❯ Every morning at 9am, check Hacker News for AI news and send me a summary on Telegram.
```

### 常见问题

**Q: Hermes 和 ChatGPT 有什么区别？**

A: Hermes 能执行终端命令、记住对话、创建技能、在多平台工作。ChatGPT 只能聊天。

**Q: 需要付费吗？**

A: Hermes 本身免费。模型调用需要 Provider 的 API Key 或订阅。

**Q: 能在手机上用吗？**

A: 可以！通过 Telegram/Discord/WhatsApp 等，或者在 Android 上用 Termux 直接安装。
