# 01-快速上手

> 从安装到第一次对话，60 秒内完成 Hermes Agent 的基本配置。

---

## 第一步：概念解释

**Hermes Agent 是什么？**

Hermes Agent 是一个能自我改进的 AI Agent。它不是绑定在 IDE 的代码助手，也不是单一 API 的聊天机器人。它是一个自主运行的 Agent，越运行越聪明。

核心特点：
- **学习闭环**：自动创建技能、改进技能、保存记忆
- **多平台**：可在 Telegram、Discord、Slack、CLI 等平台使用
- **多模型**：支持 18+ Provider，随时切换
- **终端后端**：可在本地、Docker、SSH、云上运行

---

## 第二步：类比理解

**把它想象成一个实习生**

传统聊天机器人 → 像 ChatGPT，每次对话都是新的，不记得你
代码助手 → 像 Copilot，只懂代码，绑在 IDE 里
Hermes Agent → 像一个实习生，能：
  - 执行终端命令
  - 记住你的项目偏好
  - 学习新技能并保存
  - 在 Telegram 和电脑上都能工作

**关键类比：学习闭环 = 实习生的笔记本**

每次完成复杂任务后，实习生会在笔记本上记录：
- "这个项目用 Go 1.22 + sqlc"
- "这个服务器的 SSH 端口是 2222"
- "这个流程我学会了，下次直接用"

Hermes 的 Skills 和 Memory 就是这个笔记本。

### 安装方式一：一键安装（推荐）

#### Linux / macOS / WSL2

```bash
# 一行安装（约 60 秒完成）
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash

# 安装完成后，重载 shell 配置
source ~/.bashrc  # 或 source ~/.zshrc

# 验证安装
hermes version  # 显示版本号
hermes doctor   # 诊断检查
```

#### Android (Termux)

```bash
# Termux 专用安装（自动检测 Android 环境）
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash

# 或使用 pip 显式安装
pip install "hermes-agent[termux]"
```

Termux 安装说明：
- 自动使用 Termux pkg 安装系统依赖（git、python、nodejs、ripgrep、ffmpeg）
- 自动设置 ANDROID_API_LEVEL
- 默认跳过浏览器/WhatsApp 组件（Android 上未经测试）

#### Windows

```bash
# 不支持原生 Windows！必须使用 WSL2
# 步骤 1：安装 WSL2
wsl --install  # PowerShell 中运行

# 步骤 2：在 WSL 终端中运行 Hermes 安装命令
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash

# 步骤 3：重载 shell
source ~/.bashrc
```

#### 安装脚本做了什么？

一键安装脚本自动完成以下所有步骤：

| 步骤 | 说明 |
|------|------|
| 1. 安装 uv | Astral 的快速 Python 包管理器 |
| 2. 安装 Python 3.11 | 通过 uv 安装（无需 sudo） |
| 3. 安装 Node.js v22 | 用于浏览器自动化和 WhatsApp |
| 4. 安装 ripgrep | 快速文件搜索 |
| 5. 安装 ffmpeg | 音频格式转换（TTS 用） |
| 6. 克隆仓库 | git clone --recurse-submodules |
| 7. 创建虚拟环境 | uv venv |
| 8. 安装依赖 | pip install -e ".[all]" |
| 9. 设置全局命令 | 创建 hermes 符号链接 |
| 10. 配置目录 | 创建 ~/.hermes 结构 |

### 安装方式二：手动安装（高级用户）

如果你想完全控制安装过程：

```bash
# 步骤 1：安装 uv（Python 包管理器）
curl -LsSf https://astral.sh/uv/install.sh | sh

# 步骤 2：克隆仓库（含子模块）
git clone --recurse-submodules https://github.com/NousResearch/hermes-agent.git
cd hermes-agent

# 步骤 3：创建虚拟环境（Python 3.11）
uv venv venv --python 3.11
export VIRTUAL_ENV="$(pwd)/venv"

# 步骤 4：安装依赖
# 完整安装（推荐）
uv pip install -e ".[all]"

# 或最小安装（无 Telegram/Discord/cron）
uv pip install -e "."

# 步骤 5：可选 RL 训练后端
uv pip install -e "./tinker-atropos"

# 步骤 6：可选 Node.js 依赖（浏览器自动化/WhatsApp）
npm install

# 步骤 7：创建配置目录
mkdir -p ~/.hermes/{cron,sessions,logs,memories,skills,pairing,hooks,image_cache,audio_cache,whatsapp/session}
cp cli-config.yaml.example ~/.hermes/config.yaml
touch ~/.hermes/.env

# 步骤 8：设置 API Key（至少一个 LLM 提供商）
hermes config set OPENROUTER_API_KEY sk-or-v1-your-key-here

# 步骤 9：添加全局命令
mkdir -p ~/.local/bin
ln -sf "$(pwd)/venv/bin/hermes" ~/.local/bin/hermes

# 步骤 10：添加到 PATH（如果 ~/.local/bin 不在 PATH 中）
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc && source ~/.bashrc

# 步骤 11：验证安装
hermes version
hermes doctor
```

### 常见问题

| 问题 | 解决方案 |
|------|----------|
| `hermes: command not found` | 重载 shell：`source ~/.bashrc`，或检查 PATH 是否包含 ~/.local/bin |
| `API key not set` | 运行 `hermes model` 配置提供商，或 `hermes config set OPENROUTER_API_KEY your_key` |
| `Missing config after update` | 运行 `hermes config check` 然后 `hermes config migrate` |
| `Python not found` | 安装脚本会自动安装 Python 3.11，无需手动安装 |
| `Permission denied` | 确保不在 /root 目录安装，使用普通用户目录 |

> 更多诊断：运行 `hermes doctor` 会告诉你缺少什么以及如何修复。

### 常见问题

**Q: Hermes 和 ChatGPT 有什么区别？**

A: Hermes 能执行终端命令、记住对话、创建技能、在多平台工作。ChatGPT 只能聊天。

**Q: 需要付费吗？**

A: Hermes 本身免费。模型调用需要 Provider 的 API Key 或订阅。

**Q: 能在手机上用吗？**

A: 可以！通过 Telegram/Discord/WhatsApp 等，或者在 Android 上用 Termux 直接安装。
