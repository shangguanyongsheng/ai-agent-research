## 第一步：概念解释

### 安全沙箱是什么？

**给小孩解释**：
> 安全沙箱就像给 Agent 设了一个"围栏"。它只能在围栏里面玩耍，不能跑出去做危险的事情。就像小孩在游乐场里玩，有边界保护。

**一句话定义**：
> 安全沙箱是隔离 Agent 执行环境的安全机制，防止恶意或意外操作。

### 四大安全机制

```
┌─────────────────────────────────────────────────────┐
│                  安全沙箱机制                        │
├─────────────────────────────────────────────────────┤
│                                                     │
│  代码审查          执行超时          │
│  ├── 执行前检查危险代码             ├── 限制运行时间   │
│  └── 禁止危险操作                   └── 防止死循环    │
│                                                     │
│  资源限制          权限控制          │
│  ├── CPU/内存/磁盘限制              ├── 文件系统隔离   │
│  └── 防止资源耗尽                   └── 只能访问工作区 │
│                                                     │
└─────────────────────────────────────────────────────┘
```

## 第三步：安全检查示例

### 危险操作检测

```python
DANGEROUS_PATTERNS = [
    "rm -rf",           # 删除文件
    "sudo",             # 提权
    "chmod 777",        # 权限修改
    "/etc/passwd",      # 系统文件
    "DROP TABLE",       # SQL 注入
]

def check_safety(code):
    """代码安全检查"""
    for pattern in DANGEROUS_PATTERNS:
        if pattern in code:
            return {
                "safe": False,
                "reason": f"检测到危险操作: {pattern}"
            }
    return {"safe": True}
```

### 执行超时

```python
import signal

def timeout_handler(signum, frame):
    raise TimeoutError("执行超时")

def run_with_timeout(code, timeout=30):
    """带超时的执行"""
    signal.signal(signal.SIGALRM, timeout_handler)
    signal.alarm(timeout)
    try:
        exec(code)
    finally:
        signal.alarm(0)  # 取消定时器
```
