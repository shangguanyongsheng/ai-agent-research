# 🟡 06 — Agent 怎么变聪明？（进化系统）

> 💡 一句话：**每天分析错误，每月生成新技能，还能向全世界的 Agent 学习。**

---

## 两个进化层级

| 层级 | 类比 | 做什么 |
|------|------|--------|
| **进化引擎**（本地） | 📝 你的错题本 | 分析自己的错误，生成新 Skill |
| **EvoMap**（全球） | 🌍 GitHub 开源社区 | 向全世界 Agent 学习好方案 |

---

## 进化引擎：本地螺旋上升

### 每日进化（写错题本）
```
1. 收集昨天的日志
2. 分析错误模式
3. 同类错误 ≥3 次 → 记录模式
4. 同一纠正 ≥2 次 → 低风险自动修复
5. 记录改进
```

### 每月进化（技能升级）
```
1. 分析整月统计
2. 月度纠正 ≥10 次 → 生成新 Skill
3. 通知你审核
```

**简单说：犯过的错，不白犯。每次错误都是变聪明的机会。**

---

## EvoMap：向全世界学习

**EvoMap = 全球 Agent 知识市场**

| 概念 | 是什么 | 类比 |
|------|--------|------|
| **Gene** | 策略模板（怎么做） | 📖 菜谱 |
| **Capsule** | 已验证的解决方案 | 🍳 做出来的菜 |
| **GDI** | 质量评分（0-100） | ⭐ 米其林评级 |
| **Credit** | 网络积分 | 💰 贡献积分 |

### 自然选择

```
高质量方案 → 搜索排名靠前 → 更多人用 → GDI 更高 → 更靠前 ✅ 正循环
低质量方案 → 搜索排名靠后 → 没人用 → 新鲜度衰减 → 被淘汰 ❌ 负循环
```

### GDI 评分公式

```
GDI = 内在质量 35% + 使用指标 30% + 社交信号 20% + 新鲜度 15%
```

## 一个进化例子

```
Day 1-3：Agent 调用 API 超时了 3 次
Day 3：进化引擎检测到模式 → 记录"API 超时处理"
Day 30：这个月超时纠正了 15 次
Day 30：进化引擎生成新 Skill "API 超时处理最佳实践"
Day 31：你审核通过 → Agent 以后遇到超时就知道怎么处理了
同时：这个 Skill 发布到 EvoMap → 其他 Agent 也能学习 ✅
```

## 总结

> Agent 变聪明 = 吃自己的亏（本地进化）+ 学别人的经验（EvoMap）。
> 就像你既写错题本，又看知乎大佬的总结。
