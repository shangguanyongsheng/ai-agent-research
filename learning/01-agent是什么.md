# 🟢 01 — Agent 是什么？

> 💡 一句话：**Agent = 能自主干活的 AI，不是只会聊天的机器人。**

---

## 30 秒入门

你告诉 AI："帮我分析这份销售数据。"

| | ChatGPT（普通 LLM） | Claude Code（Agent） |
|--|---------------------|---------------------|
| 它做什么 | 告诉你"怎么分析" | 自己找到文件、读取、分析、出报告 |
| 能操作电脑吗？ | 不能 | 能（读写文件、运行命令） |
| 出错了怎么办？ | 等你纠正 | 自己重试 |
| 能记住以前的事？ | 不能 | 能（有记忆系统） |

**核心区别：LLM 只会说，Agent 说到做到。**

---

## Agent 的四个核心能力

```
感知（看懂需求）→ 决策（规划方案）→ 行动（执行操作）→ 学习（从错误中改进）
 👀                🧠                🤲               📈
```

| 能力 | 做什么 | 生活类比 |
|------|--------|----------|
| **感知** | 理解你的需求和环境 | 👀 眼睛和耳朵 |
| **决策** | 规划怎么做 | 🧠 大脑思考 |
| **行动** | 执行操作 | 🤲 手脚干活 |
| **学习** | 从错误中改进 | 📈 积累经验 |

## 一个完整例子

**任务**："帮我分析 sales.csv 的销售趋势"

Agent 的内心独白：
```
👀 感知：用户想分析数据，文件在当前目录
🧠 决策：先读文件 → 按月份分组 → 计算趋势 → 出报告
🤲 行动：读取文件 → 分析数据 → 生成图表
📈 学习：上次我把文件名拼错了，这次先确认文件名
```

最终结果：一份带图表的销售趋势报告，直接给你。

## 总结

> Agent 就是一个**说到做到**的 AI。你告诉它目标，它自己想办法完成。
