## 第一步：概念解释

### 进化引擎是什么？

**给小孩解释**：
> Agent 会自己变聪明！每天分析犯过的错误，每个月总结出新的技能。就像学生每天做错题本，每月总结学习方法。

**一句话定义**：
> 进化引擎 = 每日统计 + 每月进化 + 螺旋上升

### 螺旋上升模型

```
┌─────────────────────────────────────────────────────┐
│                   螺旋上升                           │
│                                                     │
│   每日进化                     每月进化              │
│   ├─ 收集日志                 ├─ 分析月度统计      │
│   ├─ 分析错误模式             ├─ 生成新 Skill      │
│   ├─ 低风险自动修复           └─ 通知决策者        │
│   └─ 记录改进                                       │
│                                                     │
│         ↑                            │              │
│         └────────────────────────────┘              │
│                   持续循环                          │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 触发条件

| 条件 | 阈值 | 动作 |
|------|------|------|
| 同类错误 | ≥3 次 | 记录模式 |
| 同一纠正 | ≥2 次 | 低风险修复 |
| 月度纠正 | ≥10 次 | 生成新 Skill |

## 第三步：实际流程

### 每日进化流程

```python
def daily_evolution():
    """每日进化 - 分析昨日日志"""
    
    # 1. 收集日志
    logs = load_yesterday_logs()
    
    # 2. 分析错误模式
    error_patterns = analyze_errors(logs)
    
    # 3. 检查触发条件
    for pattern in error_patterns:
        if pattern.count >= 3:
            # 4. 低风险自动修复
            if pattern.risk == "low":
                apply_fix(pattern.fix)
            else:
                # 5. 记录待处理
                log_pending(pattern)
```

### 每月进化流程

```python
def monthly_evolution():
    """每月进化 - 生成新 Skill"""
    
    # 1. 分析月度统计
    monthly_stats = aggregate_monthly_stats()
    
    # 2. 识别高频模式
    high_freq = find_high_frequency(monthly_stats)
    
    # 3. 生成新 Skill
    for pattern in high_freq:
        if pattern.corrections >= 10:
            new_skill = generate_skill(pattern)
            save_skill(new_skill)
            notify_decision_maker(new_skill)
```
