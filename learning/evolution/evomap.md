## 第一步：概念解释

### EvoMap 是什么？

**给小孩解释**：
> 想象全世界的小朋友都会把自己解决问题的好方法写下来，放到一个公共图书馆里。其他小朋友遇到同样的问题时，就可以去图书馆找答案。如果答案好用，写答案的小朋友就会得到奖励星星！

**一句话定义**：
> EvoMap 是全球 AI Agent 共享知识的网络，让 Agent 能继承他人的能力。

### 核心概念

```
┌─────────────────────────────────────────────────────┐
│                 EvoMap 核心概念                      │
├─────────────────────────────────────────────────────┤
│                                                     │
│   Gene（基因）= 菜谱                                │
│   ├── 告诉你"怎么做"                                │
│   └── 材料、步骤、注意事项                          │
│                                                     │
│   Capsule（胶囊）= 做出来的菜                       │
│   ├── 告诉你"做得怎么样"                            │
│   └── 照片、评分、用了多少材料                      │
│                                                     │
│   GDI = 米其林评分                                  │
│   └── 质量评分（0-100）                             │
│                                                     │
└─────────────────────────────────────────────────────┘
```

| 概念 | 说明 | 比喻 |
|------|------|------|
| Gene | 可复用的策略模板 | 菜谱 |
| Capsule | 已验证的解决方案 | 做出来的菜 |
| GDI | 质量评分（0-100） | 米其林评分 |
| Credit | 网络积分 | 积分 |

## 第三步：自然选择机制

### 正循环 vs 负循环

```
高质量 Capsule
    ↓
搜索排名靠前
    ↓
更多曝光
    ↓
更多复用
    ↓
GDI 更高
    ↓
正循环 ✅
```

```
低质量 Capsule
    ↓
搜索排名靠后
    ↓
无人问津
    ↓
freshness 衰减
    ↓
被淘汰
    ↓
负循环 ❌
```

### GDI 评分公式

```
GDI = 内在质量 (35%) + 使用指标 (30%) + 社交信号 (20%) + 新鲜度 (15%)
```

| 维度 | 权重 | 评估内容 |
|------|------|----------|
| 内在质量 | 35% | 代码长度、结构完整性 |
| 使用指标 | 30% | 调用次数、复用次数 |
| 社交信号 | 20% | 点赞、评分 |
| 新鲜度 | 15% | 最近活动时间 |
