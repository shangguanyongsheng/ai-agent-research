## 第一步：概念解释

### Agent 是什么？

**给小孩解释**：
> Agent 就像一个聪明的机器人助手。你告诉它想做什么，它会自己想办法完成任务。它能看文件、写代码、上网搜索，还能记住之前学过的东西。

**一句话定义**：
> Agent = 感知 + 决策 + 行动 + 学习

### 四大核心组件

```
┌─────────────────────────────────────────────────────┐
│                    Agent 结构                        │
├─────────────────────────────────────────────────────┤
│                                                     │
│   感知 ──► 决策 ──► 行动 ──► 学习     │
│    ↓        ↓        ↓        ↓                    │
│  理解输入   思考方案   执行操作   改进自己            │
│                                                     │
└─────────────────────────────────────────────────────┘
```

| 组件 | 说明 | 类比 |
|------|------|------|
| 感知 | 理解用户输入和环境 | 眼睛、耳朵 |
| 决策 | 思考如何完成任务 | 大脑 |
| 行动 | 执行操作（读写文件、调用 API） | 手脚 |
| 学习 | 从经验中改进 | 成长 |

## 第二步：类比理解

### 类比 1：自动驾驶汽车

| Agent 组件 | 自动驾驶对应 |
|-----------|-------------|
| 感知 | 摄像头、雷达（看路况） |
| 决策 | AI 芯片（规划路线） |
| 行动 | 方向盘、油门、刹车 |
| 学习 | OTA 升级（越开越好） |

### 类比 2：餐厅服务员

| Agent 组件 | 服务员对应 |
|-----------|-----------|
| 感知 | 听客人点菜 |
| 决策 | 安排上菜顺序 |
| 行动 | 端菜、收拾桌子 |
| 学习 | 记住客人偏好 |

## 第三步：与普通 LLM 的区别

### 对比表

| 维度 | 普通 LLM | Agent |
|------|----------|-------|
| 交互方式 | 单轮对话 | 多轮、多任务 |
| 记忆能力 | 无长期记忆 | 持久化记忆 |
| 工具调用 | 不支持 | 支持多种工具 |
| 执行模式 | 仅生成文本 | 可执行实际操作 |
| 错误处理 | 无自动重试 | 内置重试机制 |
| 适用场景 | 问答、文本生成 | 自动化工作流 |

### 例子：处理"帮我分析销售数据"

**普通 LLM**：
```
用户：帮我分析销售数据
LLM：好的，请提供数据格式...
（只能对话，不能实际操作）
```

**Agent**：
```
用户：帮我分析销售数据
Agent：
1. 读取 sales.csv 文件 ✓
2. 分析数据趋势 ✓
3. 生成图表 ✓
4. 输出报告 ✓
（实际完成了任务）
```

### Agent 在知识体系中的位置

```
AI Agent 知识体系
│
├── foundation（基础概念）
│   ├── Agent 定义 ◄── 你在这里
│   ├── Agent Harness
│   └── ReAct 框架
│
├── tools（工具平台）
│   └── Agent 需要 Tools 才能行动
│
└── evolution（进化系统）
    └── Agent 可以通过进化变得更强
```

### 相关概念

- **Agent Harness**：控制 Agent 行为的框架（方向盘、刹车）
- **ReAct**：Agent 的思考方式（思考→行动→观察）
- **Skills**：Agent 的能力（工具箱）
- **Memory**：Agent 的记忆（大脑存储）
