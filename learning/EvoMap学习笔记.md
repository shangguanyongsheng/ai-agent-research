## 🎯 学习目标

理解 EvoMap 是如何让全球 AI Agent 相互学习和进化的。

## 📚 核心概念

### 1. EvoMap 是什么？

**给小孩解释**：
> 想象全世界的小朋友都会把自己解决问题的好方法写下来，放到一个公共图书馆里。其他小朋友遇到同样的问题时，就可以去图书馆找答案。如果答案好用，写答案的小朋友就会得到奖励星星！

**技术版本**：
EvoMap 是一个全球 AI Agent 网络，让 Agent 可以共享解决方案、继承他人能力、赚取积分奖励。

---

### 2. Gene 和 Capsule 是什么？

**给小孩解释**：
> - **Gene（基因）** = 菜谱 —— 告诉你"怎么做"
> - **Capsule（胶囊）** = 做出来的菜 —— 告诉你"做得怎么样"

| 概念 | 比喻 | 内容 |
|------|------|------|
| Gene | 菜谱 | 材料、步骤、注意事项 |
| Capsule | 做出来的菜 | 照片、评分、用了多少材料 |

**关键点**：
- 一个菜谱（Gene）可以被很多人用，做出很多菜（Capsule）
- 做出来的菜好不好吃，看评分就知道

---

### 3. GDI 是什么？

**给小孩解释**：
> GDI 就像是"米其林评分"。评分高的餐厅大家都想去，评分低的慢慢就没人去了。

**评分怎么算**：

```
GDI = 菜本身好不好（35%）+ 多少人吃过（30%）+ 多少人点赞（20%）+ 最近还在营业吗（15%）
```

**关键点**：
- 好的方案 → 更多曝光 → 更多复用 → 评分更高 → 正循环 ✅
- 差的方案 → 无人问津 → 逐渐淘汰 → 负循环 ❌

---

### 4. 进化是怎么发生的？

**给小孩解释**：
> 1. 小明写了一个"修自行车"的方法
> 2. 小红用了，发现可以改进
> 3. 小红写了改进版
> 4. 小刚用了改进版，又加了新功能
> 5. 大家都用最新最好的版本

**技术版本**：

```
毛猴子发布 v1（成功率 95%）→ Agent B 改进 v2（98%）→ Agent C 扩展 v3（99%）→ 160 万人复用
```

这就是**自然选择**的数字化实现：
- 生物进化：DNA 突变 → 自然选择 → 适者生存
- AI 进化：Gene 变异 → GDI 评分 → 高质量胜出
