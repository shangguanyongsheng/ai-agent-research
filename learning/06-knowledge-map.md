## 核心概念关系矩阵

| 概念 | ReAct | 记忆 | Skills | 进化 | Hooks | Multi-Agent | 沙箱 | Prompt |
|------|:-----:|:----:|:------:|:----:|:-----:|:-----------:|:----:|:------:|
| **ReAct** | - | 使用记忆 | 调用 Skills | 产生日志 | 触发 Hooks | 单 Agent 核心 | 执行代码 | 使用 Prompt |
| **记忆** | 被 Thought 使用 | - | - | 被进化分析 | - | Agent 间共享 | - | 加载到 Prompt |
| **Skills** | 被 Action 调用 | - | - | 被进化生成 | 被 Hooks 拦截 | Agent 工具 | 安全执行 | - |
| **进化** | 分析 ReAct 轨迹 | 更新记忆 | 生成 Skills | - | - | 多 Agent 学习 | - | 优化 Prompt |
| **Hooks** | 扩展 ReAct 行为 | - | 扩展 Skills | - | - | Agent 间通信 | 安全拦截 | - |
| **Multi-Agent** | 多个 ReAct | 共享记忆 | 分工 Skills | 协作进化 | 协作 Hooks | - | 隔离执行 | 不同角色 Prompt |
| **沙箱** | 保护 Action | - | 安全执行 | - | - | Agent 隔离 | - | - |
| **Prompt** | 定义 ReAct 行为 | 加载记忆 | 选择 Skills | - | - | Agent 角色 | - | - |

## 类比 Java 生态

| Agent 概念 | Java 类比 | 说明 |
|------------|-----------|------|
| **ReAct 循环** | Servlet 生命周期 | 请求 → 处理 → 响应 |
| **全局记忆** | application.yml | 全局配置 |
| **用户记忆** | HttpSession | 用户会话数据 |
| **工作记忆** | 方法局部变量 | 请求级临时数据 |
| **Skills** | @Service Bean | 可复用的业务组件 |
| **进化引擎** | @Scheduled 定时任务 | 周期性后台任务 |
| **Hooks** | Spring AOP | 切面编程，拦截增强 |
| **日志系统** | Logback/Log4j | 持久化日志记录 |
| **Multi-Agent** | 微服务架构 | 多服务协作 |
| **沙箱** | Docker 容器 | 隔离执行环境 |
| **Prompt** | API 文档/契约 | 定义行为和接口 |

## 设计原则总结

### 1. 分层设计

```
展示层 (Web UI)
    ↓
业务层 (ReAct + Skills)
    ↓
数据层 (Memory + Logs)
    ↓
基础层 (进化引擎 + Hooks)
```

### 2. 关注点分离

| 层级 | 职责 | 模块 |
|------|------|------|
| **思考** | 分析需求，决定行动 | ReAct Thought |
| **行动** | 执行具体操作 | Skills |
| **记忆** | 存储和检索信息 | Memory |
| **进化** | 长期改进 | Evolution |

### 3. 开闭原则

- **对扩展开放**：通过 Hooks 和 Skills 扩展功能
- **对修改封闭**：核心逻辑稳定，不轻易修改
