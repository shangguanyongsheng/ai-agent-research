# 🟠 07 — 多个 Agent 怎么协作？

> 💡 一句话：**一个 Agent 不够用？组队！就像公司有产品、开发、测试各司其职。**

---

## 什么时候需要 Multi-Agent？

| ✅ 一个 Agent 够用 | 🟠 需要多个 Agent |
|-------------------|------------------|
| 写一个脚本 | 完整的产品开发流程 |
| 分析一份数据 | 并行处理多个独立任务 |
| 回答一个问题 | 需要不同专业领域 |

---

## 协作架构

```
              你
               │
               ▼
        ┌─────────────┐
        │  主 Agent    │ ← 📋 项目经理：接需求、分任务、汇总结果
        │  (Router)   │
        └──────┬──────┘
               │
        ┌──────┼──────┬──────────┐
        ▼      ▼      ▼          ▼
     PM     Dev    QA         Ops
   调研需求  写代码  写测试     部署上线
```

## 一个完整流程：开发新功能

```
1. 📋 PM-Agent：调研需求，写 PRD 文档
       ↓
2. 🏗️ Architect-Agent：设计技术方案
       ↓
3. 💻 Dev-Agent：写代码，提交 PR
       ↓
4. 🧪 QA-Agent：跑测试，出报告
       ↓
5. 🚀 Ops-Agent：部署上线，监控
```

## 怎么调用子 Agent？

```python
result = await sessions_spawn(
    agentId="dev-agent",       # 目标 Agent
    task="实现用户登录功能",    # 任务描述
    mode="run"                 # 运行模式
)
```

## 好处和代价

| 好处 ✅ | 代价 💰 |
|--------|--------|
| 专业化：每个 Agent 专注自己的领域 | 更贵：每个 Agent 都消耗 token |
| 并行：多个 Agent 可以同时工作 | 更慢：需要协调和通信 |
| 隔离：一个出错不影响其他 | 更复杂：需要设计好任务拆分 |

## 总结

> Multi-Agent = 团队作战。适合大任务，不适合小任务。杀鸡不用牛刀。
