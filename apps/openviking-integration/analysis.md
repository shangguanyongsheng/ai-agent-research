## 🎯 核心能力

### 1. 文件系统范式管理上下文

```
OpenViking/
├── memories/          # 记忆存储
├── resources/         # 资源管理
└── skills/            # 技能注册
```

### 2. 三层上下文加载

| 层级 | 描述 | 加载方式 |
|------|------|----------|
| L0 | 核心上下文 | 始终加载 |
| L1 | 相关上下文 | 按需加载 |
| L2 | 扩展上下文 | 搜索加载 |

### 3. 目录递归检索

- 结合目录定位 + 语义搜索
- 精准上下文获取
- 可视化检索轨迹

### 4. 自动会话管理

- 自动压缩对话内容
- 提取长期记忆
- Agent 越用越聪明
