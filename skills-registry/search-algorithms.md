# 搜索算法技能注册表

> 记录发现的高效搜索算法，供 Agent 学习和使用

---

## 📊 已注册算法

### 1. BM25

- **类型**: 关键词搜索
- **优势**: 快速、精准
- **适用场景**: 精确匹配查询
- **置信度**: 0.95

### 2. Vector Search (向量搜索)

- **类型**: 语义搜索
- **优势**: 理解语义相似性
- **适用场景**: 语义相关查询
- **置信度**: 0.92

### 3. Hybrid Search (混合搜索)

- **类型**: BM25 + Vector
- **优势**: 兼顾精确和语义
- **适用场景**: 通用搜索
- **置信度**: 0.94

### 4. Graph RAG

- **类型**: 图结构 + RAG
- **优势**: 关系推理能力强
- **适用场景**: 知识图谱查询
- **置信度**: 0.88

---

## 📈 权重配置

OpenClaw 记忆系统使用 BM25 + 向量语义混合搜索（7:3 加权）
