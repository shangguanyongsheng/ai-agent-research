## 与 learning/ 的区别

| 目录 | 定位 | 内容类型 |
|------|------|----------|
| **docs/** | 单一报告、调研 | 某个技术主题的深度分析报告 |
| **learning/** | 知识库 | 系统学习的完整教材 |

**示例**：
- `docs/Claude Code 源码深度分析报告.md` → 单一报告
- `learning/claude-code/` → Claude Code 完整学习知识库
