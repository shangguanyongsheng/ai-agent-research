# OpenClaw 配置指南

> 使用费曼学习法：理解配置文件的逻辑与结构。

## 📖 概念解释

**什么是配置？**

配置文件告诉 OpenClaw：
1. 使用哪个 AI 模型
2. 连接哪些聊天平台
3. 谁可以与 Agent 对话
4. Agent 能做什么

配置文件位于：`~/.openclaw/openclaw.json`

格式：**JSON5**（支持注释和尾逗号，更易读写）

## 🎯 类比理解

**把配置文件想象成"餐厅菜单"**

- 菜单列出可选菜品 → 配置列出可用模型
- 菜单标注价格限制 → 配置标注访问权限
- 菜单可以自定义 → 配置可以个性化

就像餐厅菜单不需要写满所有细节，OpenClaw 配置也有默认值。你只需要配置你关心的部分。

## 🔧 实践示例

### 最简配置

```json5
// ~/.openclaw/openclaw.json
{
  agents: { defaults: { workspace: "~/.openclaw/workspace" } },
  channels: { whatsapp: { allowFrom: ["+15555550123"] } },
}
```

这个配置：
- 设置工作目录
- 只允许指定手机号的 WhatsApp 用户对话

### 编辑配置的四种方式

#### 1. 交互式引导

```bash
openclaw onboard       # 完整引导流程
openclaw configure     # 配置向导
```

#### 2. 命令行快速修改

```bash
# 查看配置项
openclaw config get agents.defaults.workspace

# 设置配置项
openclaw config set agents.defaults.heartbeat.every "2h"

# 删除配置项
openclaw config unset plugins.entries.brave.config.webSearch.apiKey
```

#### 3. 控制面板编辑

打开 http://127.0.0.1:18789，使用 **Config** 标签页：
- 表单化编辑（带说明）
- Raw JSON 编辑（灵活修改）

#### 4. 直接编辑文件

```bash
# 用你喜欢的编辑器
nano ~/.openclaw/openclaw.json
code ~/.openclaw/openclaw.json
```

Gateway 会自动监听文件变化，**热加载生效**。

### 配置核心章节

#### 模型配置

```json5
{
  agents: {
    defaults: {
      model: {
        primary: "anthropic/claude-sonnet-4-6",
        fallbacks: ["openai/gpt-5.4"],
      },
      models: {
        "anthropic/claude-sonnet-4-6": { alias: "Sonnet" },
        "openai/gpt-5.4": { alias: "GPT" },
      },
    },
  },
}
```

- `primary`: 主要使用的模型
- `fallbacks`: 主模型失败时的备用
- `models`: 模型目录（也定义了 `/model` 命令可切换的范围）

#### 通道配置

```json5
{
  channels: {
    telegram: {
      enabled: true,
      botToken: "123:abc",
      dmPolicy: "pairing",   // pairing | allowlist | open | disabled
      allowFrom: ["tg:123"], // 仅用于 allowlist/open
    },
    whatsapp: {
      enabled: true,
      // WhatsApp 需要 QR 配对
    },
  },
}
```

**dmPolicy 策略说明：**

| 策略 | 说明 |
|------|------|
| `pairing` | 未知用户收到配对码，需要批准 |
| `allowlist` | 只有 `allowFrom` 列表中的用户可以对话 |
| `open` | 允许所有人（需要 `allowFrom: ["*"]`） |
| `disabled` | 禁止所有私聊 |

#### 群聊提及规则

```json5
{
  channels: {
    whatsapp: {
      groups: { "*": { requireMention: true } },
    },
  },
  agents: {
    list: [
      {
        id: "main",
        groupChat: {
          mentionPatterns: ["@openclaw", "openclaw"],
        },
      },
    ],
  },
}
```

群聊中 Agent 只在被提及时回复：
- `requireMention: true`: 必须提及
- `mentionPatterns`: 提及模式列表

#### Skills 配置

```json5
{
  agents: {
    defaults: {
      skills: ["github", "weather"],  // 默认技能
    },
    list: [
      { id: "writer" },                    // 继承默认技能
      { id: "docs", skills: ["docs-search"] }, // 替换默认
      { id: "locked-down", skills: [] },   // 无技能
    ],
  },
}
```

#### 心跳配置（定期检查）

```json5
{
  agents: {
    defaults: {
      heartbeat: {
        every: "30m",    // 每 30 分钟检查一次
        target: "last",  // 发送到最后对话的通道
      },
    },
  },
}
```

心跳可以让 Agent 主动：
- 检查邮件
- 查看日程
- 发送天气提醒

### 热加载机制

Gateway 自动监听配置文件：

| 模式 | 行为 |
|------|------|
| `hybrid`（默认） | 安全修改立即生效，关键修改自动重启 |
| `hot` | 只热加载安全修改，关键修改需手动重启 |
| `restart` | 任何修改都重启 Gateway |
| `off` | 禁用监听，手动重启才生效 |

**什么需要重启？**
- Gateway 端口、绑定、认证
- 插件、发现服务
- 其他配置项通常可以热加载

### 环境变量

可以在配置中引用环境变量：

```json5
{
  gateway: { auth: { token: "${OPENCLAW_GATEWAY_TOKEN}" } },
  models: { providers: { custom: { apiKey: "${CUSTOM_API_KEY}" } } },
}
```

规则：
- 只匹配大写名称：`[A-Z_][A-Z0-9_]*`
- 缺失变量会报错
- 用 `$${VAR}` 转义为字面值

### 分拆配置文件

大型配置可以用 `$include` 分拆：

```json5
// ~/.openclaw/openclaw.json
{
  gateway: { port: 18789 },
  agents: { $include: "./agents.json5" },
  channels: { $include: ["./telegram.json5", "./whatsapp.json5"] },
}
```

## ⚠️ 重要提醒

### 严格验证

配置必须完全匹配 Schema：
- 未知键 → Gateway 拒绝启动
- 类型错误 → Gateway 拒绝启动
- 无效值 → Gateway 拒绝启动

**诊断问题：**
```bash
openclaw doctor
# 查看具体错误
```

**自动修复：**
```bash
openclaw doctor --fix
```

## 📝 总结

配置文件就像餐厅菜单：
- 定义"菜品"（模型、技能）
- 设置"价格"（访问权限）
- 可以"自定义"（个性化设置）

编辑方式多样：
- 命令行快速
- 控制面板直观
- 文件编辑灵活

修改后自动热加载生效（关键配置需重启）。
