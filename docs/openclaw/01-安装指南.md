# OpenClaw 安装指南

> 使用费曼学习法：从概念到实践，5 分钟完成安装。

## 📖 概念解释

**什么是安装 OpenClaw？**

安装 OpenClaw 意味着在你的设备上部署一个"网关程序"（Gateway）。这个程序会：
1. 监听来自聊天应用的消息
2. 转发给 AI 模型处理
3. 将回复返回到正确的聊天应用

## 🎯 类比理解

**把 OpenClaw 想象成一座"桥梁"**

- 你需要先建造桥梁（安装程序）
- 桥梁连接两岸（聊天应用 ↔ AI）
- 桥梁建成后，通行是自动的（消息自动流转）

就像安装一座桥需要准备地基、建材一样，安装 OpenClaw 需要：
- Node.js（运行环境，相当于地基）
- API Key（通行证，相当于建材）

## 🔧 实践示例

### 准备工作

**检查 Node.js 版本：**
```bash
node --version
# 推荐 Node 24，最低 Node 22.14+
```

**如果没有 Node.js：**
- macOS/Linux: 使用 nvm 安装
- Windows: 从 nodejs.org 下载

### 安装步骤

#### 方式一：一键安装（推荐）

**macOS / Linux：**
```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```

**Windows (PowerShell)：**
```powershell
iwr -useb https://openclaw.ai/install.ps1 | iex
```

#### 方式二：npm 安装

```bash
npm install -g openclaw@latest
```

### 引导配置

安装后运行引导程序：

```bash
openclaw onboard --install-daemon
```

引导程序会：
1. 让你选择模型提供商（Anthropic、OpenAI 等）
2. 输入 API Key
3. 配置 Gateway 基本设置
4. 安装为系统服务（自动启动）

### 验证安装

```bash
# 检查 Gateway 状态
openclaw gateway status

# 预期输出：
# Runtime: running
# RPC probe: ok
```

### 打开控制面板

```bash
openclaw dashboard
# 自动打开浏览器：http://127.0.0.1:18789
```

OpenClaw 还支持：
- **Docker**：容器化部署
- **Nix**：包管理器安装
- **云平台**：Fly.io、Railway、DigitalOcean 等

详见官方文档 [Install](https://docs.openclaw.ai/install) 章节。

### Windows 特别说明

Windows 用户有两种选择：
1. **原生 Windows**：直接安装使用
2. **WSL2**：更稳定，推荐用于完整体验

WSL2 安装：
```bash
# 在 WSL2 内
curl -fsSL https://openclaw.ai/install.sh | bash
```

## ⚠️ 常见问题

### 问题：安装后 Gateway 未启动

**解决：**
```bash
openclaw doctor
# 诊断并修复常见问题
```

### 问题：端口被占用

**解决：**
```bash
openclaw gateway --port 18790  # 使用其他端口
# 或强制占用
openclaw gateway --force
```

### 问题：找不到 API Key

**解决：**
1. 访问模型提供商网站获取
2. Anthropic: console.anthropic.com
3. OpenAI: platform.openai.com
