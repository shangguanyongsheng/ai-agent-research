# Pending Hooks (未闭合伏笔)

This file tracks unresolved plot hooks, mysteries, and narrative threads that need resolution in future chapters.

## Format
- Each hook should have a unique ID
- Include the chapter where it was introduced
- Brief description of the hook
- Priority level (high/medium/low)
- Target resolution chapter (if known)

## Hooks
```yaml
hooks:
  - id: "hook_001"
    introduced_in: "chapter_3"
    description: "Mysterious letter received by protagonist"
    priority: "high"
    target_resolution: "chapter_8"
  
  - id: "hook_002" 
    introduced_in: "chapter_5"
    description: "Unexplained power outage at research facility"
    priority: "medium"
    target_resolution: "chapter_12"
```
