# Subplot Board

Tracks the progress and status of all subplots in the story.

## Format
Each subplot should be tracked with:
- ID: Unique identifier for the subplot
- Title: Brief name for the subplot
- Status: active, resolved, abandoned
- Chapters: List of chapters where this subplot appears
- Key Characters: Characters involved in this subplot
- Resolution Goal: How this subplot should be resolved
